### Admin — modul baru **Cerita Mereka** (`/admin/cerita`)
- Daftar cerita (foto/inisial, nama, angkatan, peran, cuplikan), tombol **Tampil/Disembunyikan** sekali klik, edit, hapus (foto ikut terhapus dari storage).
- Form: cerita (20–400 karakter, penghitung), nama, angkatan, peran, urutan, tampilkan di Beranda, **foto opsional** (dikompres WebP).
- Menu baru di sidebar admin; catatan sidebar diperbarui (testimoni tidak lagi lewat Table Editor).

### Database
- **Migrasi baru** `supabase/migrations/0002_testimonials_batch_photo.sql`: kolom `batch` (angkatan) dan `photo_url` di `testimonials`. **Harus dijalankan di SQL Editor Supabase** sebelum menyimpan cerita lewat admin (admin menampilkan pesan jelas bila belum).

### Anti-slop (Hallmark floor, pada file yang diubah)
`sloplint --tier floor` bersih (0 FAIL) untuk `page.tsx`, `cards.tsx`, `testimonial-carousel.tsx`, `carousel.tsx`:
- `transition-all` → properti spesifik; `motion-reduce:` di semua transisi transform.
- Bayangan jadi token `--shadow-card` / `--shadow-lift` (tanpa warna literal di kelas).
- Label huruf kapital berjarak ("KENALI LEBIH DEKAT", "PROFIL TSA IPB", kode divisi di pita) → sentence case, tanpa tracking.
- `focus-visible` eksplisit di tombol/tautan carousel, kartu program, `ButtonLink`, kartu video.
- Meta tanpa titik tengah.
