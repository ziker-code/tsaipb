## Yang berubah
### Fondasi
- `scripts/process-logos.mjs` — logo `logo/*.png` → `public/brand/*.webp` (latar putih → transparan dengan teknik *color-to-alpha*, trim, resize). Logo: `logo-tsa`, `logo-mark`, `logo-tanoto`, `logo-teladan-white`, `div-{eb,ti,te,be,md,sp}`.
- `scripts/gen-icons.mjs` → `src/components/icons.generated.ts`; komponen `src/components/icon.tsx` (`<Icon name="..."/>`). Seluruh Lucide diganti; paket `lucide-react` dihapus. LINE tetap glyph khusus (tidak ada di Famicons).
- `src/app/icon.png`, `apple-icon.png` — favicon dari mark logo.
- `globals.css` — token warna dari desain tim, Sora, `--ease-out-soft`, animasi CSS (marquee, pulse-ring, float), `@property` untuk sorotan logo, dukungan `prefers-reduced-motion`.
- `src/lib/divisions.ts` — logo & warna aksen per divisi.
- Motion (`motion` v14, `LazyMotion` + `MotionConfig reducedMotion="user"`): `src/components/motion/` → `Reveal`, `Stagger/StaggerItem`, `LineReveal`, `WordsReveal`, `ScrollHighlight`, `CountUp`, `Accordion`, `Carousel` (scroll-snap, tanpa library tambahan).

### Halaman
- **Navbar**: pill kaca; menjadi gelap+blur saat scroll; indikator halaman aktif bergeser (shared layout); menu mobile beranimasi; CTA emas.
- **Footer**: sesuai desain (Organisasi / Program / Informasi), ikon sosial, logo TELADAN & Tanoto. TikTok muncul otomatis bila `site.socials.tiktok` diisi.
- **Beranda** (urutan desain tim): hero judul per-baris + mark logo melayang + lengkung bawah → statistik count-up → "Kenali Lebih Dekat" (paragraf menyala mengikuti scroll) → pita marquee (foto galeri; fallback logo divisi bila < 4 foto) → "TSA IPB Berdampak" (peta, provinsi menyala saat hover, denyut Bogor) → testimoni (carousel) → Program unggulan (kartu potret) → **Kisah Inspiratif** (kategori "Cerita Inspirasi", carousel) → **Kabar Terbaru** (1 besar + 3 daftar) → **FAQ** gaya referensi (accordion gelap) → CTA emas.
- **Tentang**: hero baru, "Siapa Kami" scroll-highlight, visi kata-per-kata, misi bernomor, **Filosofi Logo interaktif** (hover/ketuk kartu → bagian logo disorot), core values dengan ikon Famicons.
- **Struktur**: bagan dengan logo divisi, kartu divisi (logo, warna, anggota, tautan ke program divisi), alur koordinasi.
- **Program Kerja**: tab divisi berlogo dengan indikator warna divisi yang bergeser, panel divisi bertema warna, transisi antar tab; mendukung `?divisi=slug`.
- **Detail proker**: hero dengan logo & cahaya warna divisi, judul per baris.
- **Kontak, Berita, Galeri, 404, login admin**: menyesuaikan gaya (pill button, bobot huruf ringan, ikon Famicons).
