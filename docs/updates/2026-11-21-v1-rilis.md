# 2026-11-21 — Rilis v1 (website publik + admin inti)

## Ringkasan
Website profil TSA IPB versi pertama sudah live di **https://tsaipb.vercel.app**, sesuai PRD v1.1 (deadline 21 Nov).

## Isi
- **Halaman publik**: Beranda (hero, statistik, video profil, peta Bogor, program unggulan, testimoni, berita, CTA), Tentang Kami, Struktur Organisasi, Program Kerja (tab per divisi + 42 halaman detail), Berita & Blog, Galeri (filter + lightbox), Kontak + form Hubungi Kami, halaman 404.
- **Admin `/admin`**: login Supabase; CRUD Berita (Markdown + pratinjau); kelola Program Kerja (unggulan, sembunyikan, YouTube, cover); Galeri multi-upload dengan kompresi WebP di browser. Pengurus, divisi, testimoni, dan pengaturan masih lewat Supabase Table Editor.
- **Data**: Supabase (Postgres + Auth + Storage) dengan RLS; seed 6 divisi + 42 proker dari PPT.
- **SEO**: `sitemap.xml` (otomatis memuat proker & artikel), `robots.txt` (blokir `/admin`), Open Graph.

## Keputusan
- Next.js 16 dengan Cache Components: data publik di-cache (`use cache` + `cacheTag`) dan di-refresh lewat `updateTag` saat admin menyimpan.
- Deploy lewat Vercel CLI (tanpa GitHub). Deploy ulang: `npx vercel@latest deploy --prod`.

## Bug yang diperbaiki saat pengujian
- URL Supabase yang berakhiran `/rest/v1/` membuat semua query gagal → kini dinormalisasi di `src/lib/supabase/env.ts`.
- React 19 mengosongkan form admin setelah validasi gagal → `useKeepValuesSubmit` di `src/components/admin/form.tsx`.
